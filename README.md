# SmartCart-Clustering-System

SmartCart Clustering System is an **Unsupervised Machine Learning project** designed to perform customer segmentation using clustering algorithms.

## 🧠 Machine Learning Approach

- Customer behavior analysis
- Grouping similar customers based on purchasing patterns and demographics

## 📌 Algorithms Used

- K-Means Clustering
- Principal Component Analysis (PCA) for dimensionality reduction

---

## 🔄 Steps Performed

- Data Cleaning & Preprocessing  
- One-Hot Encoding of categorical features  
- Feature Scaling  
- Optimal cluster selection using Elbow Method  
- K-Means clustering  
- PCA for 2D & 3D visualization  
- Cluster analysis & insights extraction  

---

## 🛠️ Tech Stack

- Python  
- NumPy  
- Pandas  
- Matplotlib  
- Scikit-Learn  
- Jupyter Notebook  

---

## 📊 Results

The model successfully segmented customers into meaningful clusters based on purchasing behavior and demographics.

These clusters help businesses to:

- Target premium customers  
- Identify budget shoppers  
- Detect inactive customers  
- Personalize promotions
